# Pal3Mien Launcher

Đây là trang tải chính thức của **Pal3Mien Launcher** dành cho người chơi
Palworld 3 Miền trên Windows Steam.

## Tải launcher

[Tải Pal3Mien-Setup.exe](https://github.com/RinNiko/PalVerify/releases/download/stable/Pal3Mien-Setup.exe)

Phiên bản chính thức:

- Launcher: **v1.0**
- PalVerify: **v1.0**

Launcher sẽ tự kiểm tra và cài bản mới khi có cập nhật. Người chơi Xbox console
và PlayStation 5 không cần cài launcher.
