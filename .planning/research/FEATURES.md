# Feature Research

## Table Stakes

- Server-owned platform classification.
- Explicit console exemption allowlist.
- Client version compatibility policy.
- Per-session challenge and replay resistance.
- Continuous heartbeat with grace periods.
- Deterministic kick reasons.
- Runtime compatibility check before enforcement.
- Structured audit evidence.
- Privacy disclosure and minimized client telemetry.

## Later Features

- Running-process and loaded-module rule checks.
- Signed release manifest and self-integrity verification.
- Independent server-side stamina budget.
- Movement, teleport, cooldown, damage-rate, and inventory anomaly checks.
- Admin review UI and configurable enforcement thresholds.

## Anti-Features

- Trusting platform, stamina, or integrity values merely because the client sent
  them.
- Exempting a generic Xbox ecosystem identifier.
- Permanent bans from a process name.
- Scanning user files or uploading software inventories.
